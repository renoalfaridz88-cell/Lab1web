# Langkah Praktikum
1. Membuat struktur dasar HTML pada file 'index.html'.
2. Menambahkan paragraf, judul (heading), format teks, gambar, dan list.
3. Membuat navigasi antar halaman menggunakan 'halaman2.html'.

Jawaban Pertanyaan Evaluasi

# 1. Apa fungsi deklarasi <!DOCTYPE html> pada dokumen HTML?
Menyatakan bahwa dokumen tersebut menggunakan standar HTML5 dan memberi tahu browser cara membaca halaman dengan benar.

# 2. Apa perbedaan antara tag, elemen, dan atribut pada HTML?
* *Tag:* Penanda awalan/akhiran (contoh: <p> dan </p>).
* *Elemen:* Kesatuan utuh dari tag pembuka, isi/konten teks, hingga tag penutup.
* *Atribut:* Informasi tambahan yang disisipkan di dalam tag pembuka (contoh: href="...").

# 3. Apa perbedaan <p> dengan <br>? Jelaskan penggunaannya.
* *<p>:* Digunakan untuk membuat paragraf baru dan otomatis memberikan jarak spasi antar paragraf.
* *<br>:* Digunakan hanya untuk pindah baris baru (line break) tanpa memberikan jarak spasi.

# 4. Apa fungsi atribut href pada tag <a>?
Berfungsi sebagai penentu URL atau alamat tujuan ke mana halaman web akan diarahkan saat link tersebut diklik.

# 5. Apa perbedaan hyperlink ke halaman internal dengan hyperlink ke website eksternal?
* *Internal:* Menghubungkan antar halaman dalam satu folder/website yang sama (contoh: ke halaman2.html).
* *Eksternal:* Menghubungkan ke website lain di internet (contoh: ke google.com).

# 6. Apa fungsi atribut src dan alt pada tag <img>?
* *src:* Menentukan lokasi/jalur penyimpanan file gambar yang akan ditampilkan.
* *alt:* Menampilkan teks deskripsi alternatif jika gambar gagal dimuat atau rusak.

# 7. Perbedaan penggunaan <ul> dan <ol>?
* *<ul> (Unordered List):* Membuat daftar poin tanpa urutan nomor (menggunakan simbol dot/bullet).
* *<ol> (Ordered List):* Membuat daftar berurutan yang menggunakan angka atau nomor.

# 8. Apa yang terjadi jika path gambar pada atribut src salah?
Gambar tidak akan muncul (pecah), dan browser hanya akan menampilkan teks alternatif yang Anda tulis pada atribut alt.

# 9. Mengapa struktur heading h1 sampai h6 perlu digunakan secara terstruktur?
Penting untuk hierarki konten halaman web agar rapi, mudah dibaca, serta membantu mesin pencari (seperti Google SEO) memahami bagian terpenting dokumen.

# 10. Apa fungsi komentar <!-- ... --> dalam kode HTML?
Sebagai catatan atau penanda kode bagi programmer yang diabaikan oleh browser, sehingga tidak akan tampil pada halaman web.
